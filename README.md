# AI Creative Studio

## Проблема

Школяр, який робить презентацію для уроку, хоче гарну картинку, але в інтернеті всі картинки однакові і не завжди зрозуміло, чи можна їх брати. Тому презентації виглядають нудно і схоже в усіх.

## Рішення

Застосунок допомагає школярам створювати унікальні зображення для проєктів за допомогою ШІ-генератора зображень і фільтрів OpenCV.

## Що вміє MVP

1. Створює зображення за описом у вибраному стилі (реалістичний, акварель, мультяшний, піксель-арт).
2. Дає застосувати до картинки фільтр: чорно-біле, розмиття, контури, сепія, віддзеркалення, яскравість, контраст, колірний сплеск.
3. Дає завантажити готову картинку на комп'ютер.

Якщо опис порожній, застосунок показує підказку. Якщо сервіс не відповів, показує повідомлення про помилку і не ламається.

## Технології

Python, Streamlit, OpenCV, Pillow, NumPy, requests.

## Як запустити

```
pip install -r requirements.txt
streamlit run app.py
```

Перевірити головну функцію окремо від сайту:

```
python ai_functions.py
```
